## About

**My Smart Wallet** is a progressive web app (PWA) by **Deskora**, built to be as easy to use as possible and to work **entirely by voice, hands-free**. Just tap the mic and say something like *"coffee 50 and juice 20"* or *"income 1000 salary"* — the app records the transactions, categorizes them and updates your balances automatically.

> **This is a simplified edition of the app.**

## Features

- 🎙️ **Hands-free voice entry** in Arabic (Egyptian dialect & Modern Standard) and English, including spoken numbers such as "fifty" or "two hundred and fifty". The mic **keeps listening until you tap stop**, so it never cuts you off mid-sentence.
- 🌐 **Bilingual interface (Arabic / English)** with a one-tap language switch.
- ✅ **Review before saving (optional)**: an option you turn on yourself under the mic; the app then shows what it understood and you tap “OK” to save or “Undo” to cancel. It is off by default so **quick recording** stays as is, and an Undo button remains available after saving either way.
- 🧠 **Smarter voice commands** (Arabic & English):
  - Several transactions in one sentence: “coffee 50 and juice 20”.
  - Pick the account by voice: “coffee 50 from bank”, “lunch 30 cash”.
  - Spoken dates: “yesterday taxi 80”, “3 days ago lunch 100”.
  - Transfers between accounts: “transfer 500 to bank”.
  - Saving toward a goal: “save 200 to vacation”.
  - Quick questions: “what’s my balance?”, “how much did I spend today?”.
  - Say “undo” right after recording to cancel it.
- 🏷️ **Custom categories** for expenses and income, recognized by voice commands when you say their name.
- 👋 **Welcome screen** on first launch, plus a **Privacy & terms** page.
- 💵 **Multiple accounts**: Cash and Bank by default, plus any accounts you add (e-wallet, savings, travel…). Rename or delete any of them (at least one must remain), transfer between them, and refer to them by name in voice commands: “coffee 50 from vodafone”.
- 🧾 **Automatic categorization** and charts for expenses and income.
- 📊 **Monthly budgets** per category with warnings when you get close to or exceed the limit.
- 🎯 **Savings goals** with progress tracking.
- 🔁 **Monthly recurring transactions** (rent, subscriptions, salary…).
- 🛒 **Shopping list** by voice, convertible into an expense once purchased.
- 🔐 **Privacy & security**: all data stays on your device, with an optional lock code and password-encrypted backups.
- 📤 **CSV export**, backup and restore.
- 📱 **Installable on your phone** and works offline once installed, with a dark mode.

## ملاحظات للمطوّر / Developer notes

- **لا ترفع** أي نسخة احتياطية (`wallet_backup*.json`) أو ملف CSV على المستودع ده.
  *Never commit any backup (`wallet_backup*.json`) or CSV file to this repository.*
- عند أي تعديل: `git add . && git commit -m "update" && git push` وبس. رقم الإصدار (`__BUILD__` في `sw.js`) بيتحدّث تلقائيًا من بصمة الملفات عن طريق `.github/workflows/pages.yml`، وشريط "تحديث الآن" بيظهر للمستخدمين.
  *After any change just `git add . && git commit -m "update" && git push`. The cache version (`__BUILD__` in `sw.js`) is stamped automatically from a hash of the app files by `.github/workflows/pages.yml`.*
- **النشر على GitHub Pages / Deploying:** Settings ← Pages ← Source: **GitHub Actions** (الـ workflow الموجود في `.github/workflows/pages.yml` بينشر الموقع). الرابط: `https://USERNAME.github.io/REPO/` (كل المسارات نسبية فتشتغل داخل أي مسار فرعي). ملف `.gitignore` بيمنع رفع النسخ الاحتياطية وملفات CSV، و`.nojekyll` بيخلي GitHub يخدم الملفات كما هي.
- **الخطوط:** محلية داخل فولدر `fonts/` (Cairo بالأوزان 400/500/600/700 وReem Kufi 500/700 بصيغة TTF، ترخيص OFL). لو غيّرت أو أضفت خط، حدّث قائمة `CORE` في `sw.js`.
  *Fonts are bundled in `fonts/` (TTF, OFL license). If you change them, update `CORE` in `sw.js`.*
- الملفات: `index.html` (الواجهة)، `app.js` (المنطق)، `i18n.js` (قاموس الترجمة عربي/English)، `sw.js` (العمل بدون إنترنت)، `manifest.json`.
  *Files: `index.html` (UI), `app.js` (logic), `i18n.js` (Arabic/English dictionary), `sw.js` (offline), `manifest.json`.*
- لإضافة أو تعديل نص في الواجهة: عدّل المفتاح في `i18n.js` (قسم `ar` وقسم `en`). التصنيفات بتتخزن بالعربي داخليًا عشان النسخ الاحتياطية القديمة تفضل شغالة.
  *To add or edit UI text, edit the key in `i18n.js` (both `ar` and `en`). Categories are stored in Arabic internally so older backups keep working.*
- الحسابات بتتخزن في `state.accounts` (`id` + `name`)، والأرصدة في `state.balances[id]`. المعرّفان `cash` و`bank` ثابتان للتوافق مع النسخ القديمة، وكل حساب جديد معرّفه `a_xxxx`.
  *Accounts live in `state.accounts` (`id` + `name`) and balances in `state.balances[id]`. The ids `cash` and `bank` are kept for backward compatibility; new accounts get an `a_xxxx` id.*
